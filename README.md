# 🎉 신나는 우리 반 자리 뽑기 (Random Seat Picker)

선생님과 학생들을 위한 교실 자리 배치표 및 무작위 추첨 웹 애플리케이션입니다.  
외부 라이브러리나 서버 없이 단일 HTML 파일(`index.html`)만으로 독립 실행되며, 긴장감 넘치는 슬롯머신 스타일의 순차 공개 연출과 자체 Web Audio 효과음, 폭죽 효과를 지원합니다.

👉 **[온라인 바로가기 (GitHub Pages)](https://skywalkerbbak.github.io/random-seat/)**

---

## ✨ 주요 기능

- 🎲 **무작위 자리 추첨 (Fisher-Yates 셔플)**: 학생 수(2~60명)와 모둠 수(1~12개)에 따라 공정하게 배분
- 🎰 **슬롯머신 스타일 순차 롤링 애니메이션**:
  - 뽑기 시작 시 전 좌석 번호가 40ms 간격으로 빠르게 회전
  - 1모둠부터 0.4초 간격으로 `착- 착-` 순차 확정(Lock-in)
  - 롤링 중 화면에 중복 번호가 나오지 않으며, 이미 락인된 번호는 롤링 풀에서 자동 제외
- 🔊 **순수 Web Audio API 효과음**: 외부 사운드 파일 없이 브라우저 내장 신시사이저로 틱음, 락인음, C Major 축하 팡파레 화음 합성
- 🎊 **Canvas 3D 입자 폭죽(Confetti)**: 추첨 완료 시 화면 가득 흩날리는 자체 물리 엔진 폭죽
- 💾 **설정 자동 저장**: `localStorage`를 통해 입력한 학생 수와 모둠 수를 브라우저에 자동 기억
- 🔄 **원클릭 다시 뽑기**: 뽑기가 완료되면 '다시 뽑기' 버튼으로 자동 전환
- 🖨️ **A4 인쇄 최적화**: 브라우저 인쇄(`Ctrl + P`) 시 칠판 배경과 버튼을 숨기고 깔끔한 흑백 종이 배치표로 출력

## ⌨️ 단축키 안내

| 키 | 기능 |
|:---:|:---|
| **Space** / **Enter** | 자리 뽑기 시작 / 다시 뽑기 |
| **F** | 전체화면 켜기 / 끄기 ⛶ |
| **M** | 효과음 켜기 / 끄기 (음소거 토글) 🔊 / 🔇 |

---

## 💻 로컬 실행 방법

외부 의존성(CDN, 프레임워크, npm)이 전혀 없으므로, [index.html](index.html) 파일을 다운로드하여 더블 클릭하면 인터넷 연결 없이도 즉시 실행할 수 있습니다.
